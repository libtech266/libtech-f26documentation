# Installing Omeka

Installed imagemagick and enabled mod_rewrite. 

Added an Omeka directory to /var/www/html/omeka in apache2.conf. 

Created a omekauser and omeka database in mysql. Granted all privileges to omekauser. 

Downloaded Omeka zip from Omeka GitHub Repository and unzipped the file. 

Renamed directory with Omeka version to 'Omeka.'

Adjusted permissions for Omeka and www-data user.

Set up account info in db.ini file. 

Finished installing Omeka via the webpage.
