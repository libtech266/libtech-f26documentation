# Installing Wordpress

Created new VM with slightly more power. 

Reinstalled LAMP stack and mysql installation. 

Downloaded Wordpress zip, installed unzip command, and unzipped the file. 

Granted www-data user permissions to install files and write to specific directories for Wordpress. 

Made a directory for Wordpress uploads and granted write access. 

Created a new mysql user as the root and granted permissions to the wordpress database. 

Set up account information for Wordpress in wp-config.php.

Finished installing Wordpress via the webpage.
